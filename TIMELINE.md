# Timeline · เส้นเวลา

Dated trail of GitHub account [`Nonarkara`](https://github.com/Nonarkara).

**How to read this.** Dates on public repos are GitHub `created_at` (UTC) from the public API on 2026-08-31. They mark when the *repository object* was created, not always when a version first appeared as a URL. Private repos have **no dates here** — the public API does not yield them, and this history does not invent them. Full table: [`artifacts/public-repos.csv`](artifacts/public-repos.csv).
